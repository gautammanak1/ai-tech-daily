## Getting Started — Code Examples

For developers looking to leverage OpenAI’s latest tools, here are practical examples using the **Agents SDK** and the standard **API**.

### Example 1: Basic Chat Completion with GPT-5.6 Sol
This example demonstrates how to call the latest model using the Python SDK. Note the `model` parameter specifying the new architecture.

```python
import openai

client = openai.OpenAI(
    # Assuming your API key is set in the OPENAI_API_KEY environment variable
    api_key="your-api-key-here"
)

response = client.chat.completions.create(
    model="gpt-5.6-sol",
    messages=[
        {"role": "system", "content": "You are a helpful assistant designed to provide accurate technical analysis."},
        {"role": "user", "content": "Analyze the recent trends in AI agent autonomy and summarize the security risks."}
    ],
    temperature=0.7,
    max_tokens=1024
)

print(response.choices[0].message.content)
```

### Example 2: Building a Multi-Agent Workflow with Agents SDK
Using the `openai-agents-python` library to create a simple agent that delegates tasks. This showcases the agentic capabilities that led to recent headlines.

```python
from openai import OpenAI
from openai.agents import Agent, Runner

# Define a specialized agent for research
research_agent = Agent(
    name="Researcher",
    instructions="You are an expert researcher. Search for the latest news on OpenAI's infrastructure projects.",
    model="gpt-5.6-sol"
)

# Define a main orchestrator agent
orchestrator = Agent(
    name="Orchestrator",
    instructions="You manage the research process. Delegate queries to the Researcher.",
    handoffs=[research_agent]
)

# Run the workflow
result = Runner.run_sync(orchestrator, "Find details on the Savannah data center.")

print(f"Research Result: {result.final_output}")
```
